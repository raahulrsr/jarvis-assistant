# Jarvis Assistant

A Python-based voice assistant that uses **speech recognition, text-to-speech, and external APIs** to interact with users through voice commands.

## Features

* Voice-based interaction
* Speech recognition for user commands
* Text-to-speech responses
* Web search functionality
* Wikipedia-based information retrieval
* Application launching
* Command-based task execution

## Technologies Used

* Python
* SpeechRecognition
* Pyttsx3
* Wikipedia API

## How It Works

1. The application listens for a voice command from the user.
2. Speech is converted into text using speech recognition.
3. The assistant processes the requested command.
4. The appropriate action is performed.
5. The assistant provides a response using text-to-speech.
